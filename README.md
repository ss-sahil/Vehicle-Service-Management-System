# Vehicle Service Management System

## About the Project

The Vehicle Service Management System is a DBMS mini project developed using MySQL. It helps manage customer details, vehicle information, mechanic records, service history, and billing information.

## Technologies Used

* MySQL
* SQL
* MySQL Workbench

## Database Tables

1. Customers
2. Vehicles
3. Mechanics
4. Service_Records
5. Bills

## Features

* Store customer and vehicle details.
* Maintain mechanic information.
* Record vehicle servicing and repair status.
* Manage bills and payment methods.
* Retrieve information using SQL queries.
* Generate reports using JOIN, GROUP BY, COUNT, and SUM.

## How to Run

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and connect to your server.
3. Open the `vehicle_service_management.sql` file.
4. Execute the SQL script to create the database, tables, and sample records.
5. Run the queries to view the results.
